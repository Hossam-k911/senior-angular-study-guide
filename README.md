# Senior Angular Study Guide

A bilingual, dark-mode study site for a senior Angular interview. Open `index.html` through any static web server, or publish the directory from a GitHub Pages branch. The committed `data.js` contains the compiled guide, so GitHub Pages does not need a build step.

To update the content, edit `guide.md`, run `npm install` once, then `npm run build`. Commit the regenerated `data.js` with the source. The original interview guide is available as `guide.md`.
